# **App Name**: Mic Mitr Portfolio

## Core Features:

- Home Page Display: Display company name, short introduction, and portfolio previews.
- Portfolio Categories: Categorize portfolio items into Graphics, Video, Voice Over, AI UGC Videos, and Meta Ads.
- Meta Ads Sub-sections: Create sub-sections within Meta Ads for 3-Day Setup and Premium Plan Setup.
- Portfolio Item Cards: Display portfolio items in card format with video/image preview, company name, and description.
- Navigation Bar: Implement a navigation bar with links to Home and Portfolio.
- Footer: Add a footer with the company name and a tagline.
- AI-Powered Content Recommendations: An AI tool will decide which portfolio items to showcase, focusing on projects most relevant to the viewer's inferred interests or current industry trends.

## Style Guidelines:

- Background color: Black (#000000) for a modern and professional base.
- Primary color: Bright yellow (#FFDA63) for highlights and buttons.
- Text color: White (#FFFFFF) for main text to ensure readability.
- Headline font: 'Poppins', a geometric sans-serif (a font requested by the user). Note: currently only Google Fonts are supported.
- Body font: 'Inter', a grotesque-style sans-serif (a font pairing for 'Poppins').
- Ensure a responsive design that adapts to all devices (mobile, tablet, desktop).
- Use clean borders and spacing for a professional agency look.
- Implement smooth hover effects and animations on cards and buttons.
- Minimalist and modern icons aligned with each portfolio category.
